# 文档目录索引

文档按用途分组，避免把设计、性能、诊断、参考和教学材料继续混在同一个目录中。

- `ascend-design/`：Ascend 架构、接口、算子设计与实现规范。
- `ascend-performance/`：性能规划、优化阶段、基准报告和调参开关。
- `ascend-diagnosis/`：profiling 记录、瓶颈分析、适配与调试过程。
- `ascend-reference/`：通信库参考、接口差异和实现对比。
- `ascend-articles/`：文章草稿与大纲。
- `ascend-assets/`：Ascend 文档共用的图片和示意图。
- `deepep-teach/`：教学材料和引导课程。
- `legacy/`：DeepEP V1 与 NVSHMEM 的归档文档。

项目整体介绍仍保留在仓库根目录 `README.md`。
